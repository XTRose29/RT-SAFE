# Third-party components

- `SimWorld/simworld/` is the locally supplied SimWorld Python implementation. Its supplied Apache-2.0 license is retained in `SimWorld/LICENSE`. The release changes its top-level imports to load optional city-generation dependencies lazily.
- Locally bundled DM Sans and Space Grotesk fonts retain their SIL Open Font License files in `website/public/fonts/`.
- Python and JavaScript dependencies retain their own licenses. They are installed through package managers and are not vendored.
- Unreal Engine and marketplace runtime assets are not included. Their distribution terms must be handled separately.

A project-wide license for original RT-SAFE code is pending the authors' selection. This notice does not relicense third-party components or the manuscript.
